# deviance.propensity.data

This repository contains supplementary materials for the study **“Digital Engagement and Identity Online: Measuring Deviance Propensity Through Projective Vignette Methodology.”**

It includes the survey summary, raw data export, statistical summaries, and visualizations referenced in the manuscript.

## Contents

- `index.md` — GitHub Pages results page
- `Data_All_260421.pdf` — survey summary report
- `Data_All_260421 (1).zip` — raw survey data export
- `visual_summary.csv` — summary values used in the visualizations
- `.png` and `.svg` files — visual summaries of key findings
